## 1. 任务、基线与研究问题

本作业研究下一 token 预测：给模型一段文字，让它预测紧接着出现的 token。token 是固定 BPE 分词器切出的文本单位，不一定是一个完整单词。输入 [A, B, C] 时，对应目标是 [B, C, D]；预测 C 时只能使用 A、B，不能提前看到答案。评分按独立的 256-token 因果窗口执行，不允许跨窗口保留状态。

固定基准为 WikiText-2，词表大小 2,048。评分指标 BPB 是每个原始 UTF-8 字节对应的平均负对数概率，越低越好。公式为 BPB = 全部目标的负自然对数概率之和 / (ln(2) × 原文 UTF-8 字节数)。字节数包括首 token 的字节；每个 split 除首 token 外的目标各评分一次。训练损失则是一个随机小批次上的交叉熵，不可直接与 BPB 相减。

原始模型为 4 层 GPT，宽度 128，4 个注意力头，共 1,088,256 个参数。它使用可学习 token 和位置向量、前置 LayerNorm、因果自注意力与前馈模块，并共享输入 embedding 和输出层权重。模型、配置、分词器、数据和固定评估器保留原样。本文的机制改动仅在训练期间另外维护一份指数移动平均（EMA）权重。

初始基线 B0 使用 seed 17、1,200 步、每步 32 条序列、每条 256 个目标，共 9,830,400 个训练目标。学习率、AdamW 和梯度裁剪均沿用 starter。初始基线验证 BPB 为 2.071087433，冻结后完整测试 BPB 为 2.1012651958438786。

研究问题是：不增加训练目标数、不修改模型结构时，对同一训练轨迹的后半段参数做 EMA，能否比最后一步原始权重得到更低的验证 BPB？机制可有负结果；不会把未获得支持的改进写成既定结论。

## 2. 观察、假设与 EMA 方法

基线在第 300、600、900、1,200 步的验证 BPB 分别为 2.331084、2.184163、2.106116、2.071087。四个点持续改善，但每个 300 步区间的改善缩小。记录的训练损失只是每隔 100 步的单个小批次值，不是 100 步平均；小幅反弹不能证明优化不稳定。这些证据不足以认定过拟合，也不足以认定完全收敛。

待检验假设：平均一段训练过程的参数，可能减少最后一步权重的偶然波动。竞争假设：当模型仍在改善时，较早、较差的参数会拖慢平均权重的进步，反而增加验证 BPB。这两种解释均在读取 EMA 结果之前提出。

预先固定 decay = 0.99，start = 600。设 w_t 为第 t 次优化器更新后的原始状态，m_t 为平均状态：第 600 步先令 m_600 = w_600；随后每步令 m_t = 0.99 × m_(t-1) + 0.01 × w_t。第 601 至 1,200 步共进行 600 次平均更新。权重贡献的半衰期约为 68.97 次更新；初始化权重的剩余系数为 0.99^600，约 0.002405。

ema.py 独立克隆模型 state_dict。浮点状态按公式平均，整数状态直接复制；导出的状态也是独立副本。每次平均发生在 optimizer.step() 之后，不修改原始权重、优化器或随机采样。最终建立独立模型载入平均权重并验证，保存为普通 PyTorch 检查点。推理只用一套权重，既没有模型集成，也没有测试时训练或检索库。

实现由 18 项测试覆盖：原有 5 项契约检查；EMA 载入后的同等检查；数值公式、整数 buffer、状态独立性、初始化时点、参数边界、检查点往返加载与绑定权重；以及真实小 GPT 在开关 EMA 下原始训练轨迹逐张量一致。新测试先失败，再在实现后通过。完整 seed 17 对照进一步确认原始权重的全部 53 个状态张量与初始基线逐位相等。

## 3. 同预算实验、消融与结果

B0 是原始完整基线。E0/E1 是同一次 seed 17 训练的原始/平均权重；R0/R1 是预先确定的 seed 23 复核。所有模型结构、优化器、训练步数、batch size 与训练目标数相同。E0 与 E1 的唯一区别是评估时采用哪套权重，因此这一对同时提供同预算对照与关键机制消融；R0/R1 同理。没有继续搜索第二个 decay、不同结构或更长训练预算。

| 编号 / 权重 | seed | 累计训练目标 | 验证 BPB |
|---|---|---|---|
| B0 / raw | 17 | 9,830,400 | 2.071087433 |
| E0 / raw | 17 | 9,830,400 | 2.071087433 |
| E1 / ema | 17 | 9,830,400 | 2.075051428 |
| R0 / raw | 23 | 9,830,400 | 2.076011404 |
| R1 / ema | 23 | 9,830,400 | 2.079743500 |

EMA 减去原始权重的验证 BPB：seed 17 为 +0.003963995，seed 23 为 +0.003732096。正值表示 EMA 更差。两次配对均显示本设置下没有改善，因此本文没有证据支持 EMA 提升预测质量。消融说明差异来自导出的平均状态，而不是增加训练目标数；跨种子比较不能替代同轨迹配对。

按最低验证 BPB 选择 B0（seed 17，raw 权重），并在完全相同数值时保留列表中先出现的基线。最终完整测试 BPB 为 2.1012651958438786。B0 的已测测试 BPB 为 2.1012651958438786；其余候选没有用测试分数筛选。最终提交的模型与已实现的 EMA 候选明确区分，不把基线结构或未经证实的平均机制宣称为创新成果。

结果与“平均权重滞后于仍在进步的原始权重”这一解释一致，但没有直接测量参数轨迹的几何性质，不能把它当作已证实的因果机制。仅两个种子和一个 decay，不足以断言 EMA 对其他训练长度、启动时点或任务无效；也未进行统计显著性检验。
